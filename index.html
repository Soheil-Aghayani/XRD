Reference provenance & method

Matching: one-to-one greedy assignment, smallest angular error first. Score = reference coverage × (1 − 0.5 × mean absolute error / tolerance) × 100. Only reflections within the selected scan range are evaluated. Unexplained peaks refer to each candidate individually.

The local reference tables are selected positions from a prior COD-based comparison, not complete simulated patterns. Original CIF revision and calculator version were not captured; this limitation is retained in exports. No existing sample intensities are bundled.
